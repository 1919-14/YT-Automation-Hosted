## 🌟 Overview

YT Automation Hosted runs continuous, structured content-generation loops directly in the cloud. It features 1-tap mobile control via Telegram, live terminal progress streaming, EdgeTTS voice synthesis, Pexels stock video downloads, FFmpeg video compositing, and automated YouTube publishing.

| Capability | What it does |
|---|---|
| 📱 **Telegram Remote Control** | 1-tap phone control for Short/Long videos with live progress cards |
| 🧠 **Story Bible Memory** | Tracks series, canon facts, character sheets & unresolved threads in SQLite |
| 🧭 **Decision Engine** | Decides *new video* vs *continue series* vs *conclude series* automatically |
| ✍️ **Script Generation** | LLM-written retention-optimized scripts: hook → scenes → ending → CTA |
| 🔊 **EdgeTTS & Whisper** | Natural voice synthesis with frame-accurate subtitle timing |
| 🎥 **Pexels & FFmpeg** | Automated B-roll searching, clipping, dynamic subtitle rendering, and upload |
